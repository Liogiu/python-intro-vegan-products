# Vegan Products Inventory Manager

Simple Python project for managing a small vegan products inventory.  
This is an introductory exercise from my Data Science & Python course and represents my first complete Python script.

---

Project Features

- Add new products with quantity, purchase price and selling price  
- List all available products  
- Register sales and update inventory  
- Track gross revenue and net profit  
- Save inventory and profits to JSON files  
- Simple command-line interface

How to Run the Program

1. Make sure you have **Python 3** installed  
2. Run the main script:
python vegan_shop.py

Follow the commands shown in the menu:

- `aggiungi` – add product  
- `elenca` – list inventory  
- `vendita` – register a sale  
- `profitti` – show total profits  
- `aiuto` – show commands  
- `chiudi` – exit program  

---

Data Storage

The program automatically saves two JSON files:

- `inventory.json` → product inventory  
- `profits.json` → gross revenue & costs  

Both are updated after each operation.
